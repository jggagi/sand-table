# 掌上园林 · 苏州五园

[打开统一入口](https://suzhou-gardens.jggagi.chatgpt.site)

入口现为淡彩手绘风格的苏州古城游览示意图。点击图上的留园、拙政园、狮子林、网师园或沧浪亭，直接进入各园的独立作品；园内点“返回地图”或浏览器后退，地图保留刚游过的园子。键盘 Tab 选择园名、Enter 入园。悬停或聚焦点位会显示该园的真实微缩景观预览。

本目录是用户于2026-10-04明确要求的独立入口。手写静态HTML/CSS/JavaScript及本地图片全部位于 `dist/` 并纳入Git；无构建步骤、包安装、共享三维引擎、后端或外部字体。五园仍按各自目录独立运行。入口及各园沿用所有者私有访问。

## 本地运行

在仓库根执行：

```bash
cd suzhou-gardens/portal
python3 -m http.server 4180 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:4180/`。地图点位会进入现有线上园林，需要对应Sites访问权限。本地入口无需WebGL；各园运行要求见其README。

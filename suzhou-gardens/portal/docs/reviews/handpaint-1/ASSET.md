# 手绘风格地图资产

用户要求旅游地图用精美手绘风格。`dist/assets/suzhou-handpaint.jpg` 是本轮使用图像生成工具创作的淡彩地图插画，不是人工绘画、实景照片、测绘地图或三维园林截图。

## 创作与来源

仅生成一次，使用本项目旧示意图的无文字布局截图作为位置参考。提示要求俯视方形构图、暖象牙色纸张、细笔线描、青绿河道与桥、白墙灰瓦的微小院落、五处不同园景意象；不要文字、界面、图例或装饰边框。参考保持留园在西、拙政园与狮子林相邻、网师园与沧浪亭在南侧的概括关系。未导入第三方照片、地图瓦片、测绘坐标或在线字体。

输出原图为1254×1254、不透明RGB PNG；仅转换为JPEG质量91、无色度抽样以减少手机传输量，没有缩放、裁切或以程序重绘插画。交付JPEG仍为1254×1254，631931字节，SHA256：

```
c23cf283a32d9cc3bce3c4b2d65a856a04a49399f31d0e6b66be9e6b4d795675
```

地图本体由本地JPEG显示；五个真实链接、中文园名、引线与朱色点位是HTML/SVG交互标注。SVG仅承担连接线与定位点，不绘制建筑、地形或手绘背景。引线锚点按生成插画中实际园景中心放置，属于图像坐标，不能解释为GIS位置。下方五园预览继续沿用此前真实WebGL渲染截图。

街巷、园界、建筑与水系均为艺术概括，不声称真实园林平面、历史建筑复原、路网准确性或步行距离。页面保留“游览示意图 · 点位与街巷经过概括，不用于实地导航”及“艺术化微缩 · 非等比例复原”。

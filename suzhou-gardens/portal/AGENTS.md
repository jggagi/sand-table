# 苏州园林入口开发约束

用户于2026-10-04要求用一个ChatGPT Site作为五园入口。此目录是独立静态门户，不属于上层或某园应用。

- 所有入口页面、预览资产、截图、配置与说明位于本目录。
- dist为手写静态源码并跟踪提交；没有生成式构建、npm workspace、统一三维注册表或跨园运行时依赖。
- 卡片仅导航到已经发布的五个园林Site，不改变其源码、身份或访问范围。
- 缩略图必须来自各园真实渲染；不使用生成图冒充截图。
- 发布使用本入口独立hosting身份，凭据与发布缓存不提交。
- 验证桌面/手机/键盘/链接/图片加载，诚实记录检查边界。

用户随后选择CloudBase静态托管，用默认网址向国内朋友分享。允许在本目录生成独立上传包：复制五园既有构建产物到各自子路径，仅改写包内入口链接。保留原Sites入口与五园源码，凭据及生成包缓存不提交。

# 苏州园林统一入口

用户请求：用一个Site作为五座园林入口。

交付独立的静态选园页面，展示留园、网师园、拙政园、狮子林、沧浪亭的真实三维缩略图、各自主题与入园链接。兼容手机和键盘；默认同标签导航，可通过浏览器返回入口。沿用ChatGPT Site托管与私有访问，不初始化上层应用，不合并五园场景。


本轮用户明确选择五园画面与手机打磨：入口同步更新五园最终真实缩略图、记录检查与发布结果，并生成包含最终独立构建产物的 CloudBase 上传包。

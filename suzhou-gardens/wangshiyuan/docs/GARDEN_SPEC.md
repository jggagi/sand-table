# 掌上网师园 · 独立微缩资产规格

本稿记录网师园的独立程序化资产、观景配置与文案约定。输出目录为 `/tmp/suzhou-wangshiyuan-assets/`，供后续应用集成与视觉核对；文件存在不代表应用已运行、站点已发布或验收已完成。

## 产品与空间主题

产品名为“掌上网师园”，主题为“小园大境”。以紧凑池面、开放临水亭阁与层层小院构成可旋转、可缩放的实体沙盘意象。观察重点是池面留白、建筑与水的贴近关系，以及门廊之间的前后空间。

场景采用正交相机和浅色实体底座。建筑、树与山石是本项目生成的艺术形体；布局与尺寸来自本稿构图，不作为实地测绘、完整游线或建筑修缮依据。彩霞池、濯缨水阁、月到风来亭、殿春簃等名称作为待核对的主题线索使用，其资料状态见 `REFERENCES.md`。

模型把殿春簃式院景安排在底座东侧，以便在一张沙盘中保留池景与小院的疏密关系。这是艺术化压缩的构图决定，须随可靠空间资料和实际画面继续核对。省略住宅、室内、题刻、精细雕饰及完整园界；不凭空补出这些细节。

## 坐标、边界与尺度

- 采用右手坐标：`x` 为模型左右，`z` 为模型前后，`y` 为高度；所有地上构件以 `y = 0` 为地面。
- 底座平面为 `24 × 20` 模型单位，边界 `x ∈ [-12, 12]`、`z ∈ [-10, 10]`。
- 底座从 `y = -0.7` 延伸至地面。场景包络预留 `min = [-12, -0.75, -10]`、`max = [12, 6.2, 10]`；包络应由最终几何复核。
- 数值以可读的微缩比例服务构图，模型单位与实地米数没有建立换算关系。
- 树木仅四棵，另有一小丛竹；树干与枝冠参数高度最大 `4.8`，用于少量遮掩与轮廓，不形成大面积密林。

视口拟合沿用现有相机接口：`zoom = max(0.01, min(max(1, height) / verticalSpan, max(1, width) / horizontalSpan))`。同时使用宽、高约束，让手机竖屏按横向包络缩放，保持全景底座在画面内。局部机位也按各自范围拟合。相机距离负责观察方向与高度，正交画面尺寸由 `zoom` 决定。

`CAMERA_LIMITS` 保持现有接口：极角范围 `0.28..1.35`，相对预设缩放范围 `0.65..2.4`。预设切换、拖动中断、触摸、resize、reduced motion 和连续点击的行为依赖应用控制器；本稿没有实现或验证这些运行行为。

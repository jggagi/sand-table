首次新增外部资产时，在本文件补充表格或新增 `assets-sources.md`，逐项记录：

| 字段 | 内容 |
| --- | --- |
| asset_id | 与场景对象或资产清单对应的稳定 ID |
| 作者/来源 | 作者、可访问的原始链接或自行制作说明 |
| 用途 | 仅参考 / 实际打包到站点 / 修改衍生 |
| 使用条件 | 明确许可或授权依据；未知写未知 |
| 修改记录 | 简化、重拓扑、材质重制等实际处理 |
| 准确性 | 参考支持的部分，以及艺术化、估计和占位部分 |

# 历史 Codex 任务：M1 留园微缩构图原型

状态：**M1 已交付，后续获授权的 M2 艺术化打磨亦已交付**。原任务书创建于 2026-10-03，以下保留原验收范围；当前结果见 [M2 报告](docs/reviews/m2/REPORT.md)。

## 可直接发给 Codex

> 在本仓库 `suzhou-gardens/liuyuan/` 内实现《掌上留园》的 M1 可交互构图原型。
>
> 先阅读上层 `suzhou-gardens/AGENTS.md`，再阅读留园目录内的 `AGENTS.md`、本文件、`docs/LIUYUAN_SPEC.md` 和 `docs/IMPLEMENTATION_PLAN.md`。首座已经确定为留园，方向是具有实体沙盘感的微缩景观，不做摄影测量或全园 1:1 重建。
>
> 交付一个 React + TypeScript + Vite + React Three Fiber + Drei 的可运行单页应用。三维内容包含同一底座上的中部池景、简化廊院连接、东部冠云峰庭院，以程序化几何和统一基色完成构图。实现正交相机旋转缩放、四个观景点和一键复位，并能在桌面和手机布局中操作。
>
> 布局、相机预设和文案分离配置，关键资产拥有稳定 ID，允许未来替换为 GLB。当前不要实现第一人称、屋顶抬升、复杂水反射、全园导航、后端、多园切换或通用编辑器。
>
> 必须运行可执行的检查，提供真实网页截图、使用说明和已知限制。缺少资料时采用明确标记的艺术化简化；缺少浏览器能力时诚实记录，不伪造截图或验证结果。完成 M1 后停止，等待对构图和视觉效果的反馈。

## 必须完成

### 1. 项目启动

在 `suzhou-gardens/liuyuan/` 建立应用，保留现有文档。所有应用代码、依赖、锁文件、构建配置、资产、测试和截图均放在留园目录内；不在上层初始化项目，不依赖或修改兄弟园林目录。

提供并实际验证 `dev`、`build`、`preview`、`typecheck`、`test` 和 `test:e2e` npm scripts；`test` 不默认进入 watch 模式。提交锁文件，在 README 记录所需 Node/npm 版本、首次安装与后续 `npm ci` 的使用方式。以下相对路径均以留园目录为基准。

应用不依赖外部模型、图片热链、远程字体或 API。基础页面与场景使用本地代码和资产即可启动。

### 2. 一张有构图的三维场景

包含薄底座、不规则水面、山石地形、涵碧山房/明瑟楼的简化建筑组合、转折回廊、至少一个真实可透视的墙洞、东部独立石峰庭院和少量有疏密变化的植物。

冠云峰允许是 M1 艺术化占位，但必须有瘦高、不对称、多段变化的轮廓，与中部厚重山石明显不同。不能只摆一个默认 box、cone 或 cylinder 后宣布完成。其精细孔洞及参考匹配属于 M2。

没有拍照级精细模型也要完成整体配色、基本阴影、屋顶体量和四个角度的层次；不要只交一张灰色空白底盘。

### 3. 相机与操作

实现固定 ID 的四个预设：`overview`（全园入掌）、`waterside`（临水看楼）、`corridor`（廊间一瞥）、`guanyun`（庭中观石）。包含可键盘操作的 DOM 按钮、当前视角文案、整体复位、鼠标拖动和滚轮缩放、触摸旋转与双指缩放。

不同视口均可看到主体；限制俯仰与缩放，不翻到底座下。预设切换可被手动操作打断，快速连点不产生多套动画争抢相机。M1 不强求 3D 热点，不能渲染尚不可用的“看层次”按钮冒充功能。

### 4. 最小页面与异常处理

页面以 canvas 为主体；标题、操作栏、短文案、艺术化说明不遮住重点模型。展示真实初始化状态；WebGL 不可用或场景加载失败时显示可读错误和重试/刷新指引，不留白、不死循环。

尊重 `prefers-reduced-motion`；没有自动旋转、强制背景音乐、账号或分析追踪。

### 5. 验证与报告

单元测试至少覆盖场景/观景点 ID 一致性、预设完整性和配置边界。浏览器测试至少覆盖场景成功初始化、非空真实渲染、四个观景点切换、复位、缩放边界和移动布局。

实际应用渲染的五张截图：桌面 `overview`、`waterside`、`corridor`、`guanyun` 各一张，以及竖屏手机 `overview` 一张。建议桌面 1440×1000、手机 390×844、截图 DPR=1；动画停稳后截取。

将选定压缩截图与 `REPORT.md` 放在 `docs/reviews/m1/`，报告写出命令、退出结果、测试视口、浏览器/渲染环境、占位资产和未验证项。测试临时 trace、视频、依赖和构建缓存不提交。

## 本轮不做

## M1 完成的判断

用户能启动网页，在同一底座上看到三个互有关联的空间片段，旋转缩放并切到四个经过构图的视角。构图和交互可接受检查；资料不足与美术占位被明确标记。类型检查、构建和已执行测试有可追溯结果，截图来自真实渲染。

**不要把“应用已跑起来”写成“写实复原完成”，也不要为了等待完美模型而不交付可见页面。**

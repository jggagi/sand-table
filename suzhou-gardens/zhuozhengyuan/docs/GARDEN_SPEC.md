# 拙政园主题微缩景观规格草案

本规格描述已构建的独立程序化三维场景资产；前端产品、最终界面与部署由主代理集成。园名以及远香堂、荷风四面亭等名称用于主题意象，不表示已核对实际建筑的形制、朝向、位置或相互距离。场景不是测绘模型，也不是实物精确结构复原。

## 空间构图

- 底座为 34 × 25 的暖白矩形；数值是场景单位，不代表米或真实园林尺度。
- 中央偏前布置大片青绿不规则水池，水面作为主体留白。岸线用温和弧度与少量转折组织，避免几何圆池或规则矩形池。
- 水中布置两座非对称树岛。两岛的面积、轮廓、树冠高度应有差异，保持可读的水道与间隙。
- 北侧布置低矮的远香堂意象，以舒展屋面和轻薄的暖白墙体形成背景。堂屋的高度不应压过树岛主体。
- 荷风四面亭意象靠近偏西树岛；亭与树群、水岸共同形成小尺度停留点。少量荷叶围绕亭边和近岸水面，保持大部分水面清爽。
- 曲桥从亭边经树岛延伸至东岸，采用连续可读的折线段。桥面、落脚点与岸线衔接需由主代理检查。
- 右侧以折廊收束空间，形成竖向和转折方向的节奏。折廊与堂、亭之间保留可见的空间间隙。
- 柔和树群围绕远堂、两岛和边缘分布。树冠以不规则圆润体块组成，避免均匀等距重复。

建模坐标约定为 `x` 向东、`z` 向南、`y` 向上。池面占地约 26 × 17；远香堂意象位于北岸 `z ≈ -8.3`，西岛参考中心为 `[-6, -2.6]`，东岛参考中心为 `[4.5, -2.0]`，荷风四面亭意象参考位置为 `[-6, -0.5]`。以上平面坐标按 `[x, z]` 记，是场景构图参数而非实物测量。曲桥自亭边经岛串联至东岸，具体桥段以模型为准。池岸的不对称轮廓、桥与岛的节奏优先于建筑细节。

## 视觉语汇

暖白底座与建筑、青绿水面、低饱和树冠、克制的灰色屋顶和木色桥廊。优先让水、岛、堂、亭、桥的轮廓在微缩视角中清楚可辨。所有造型允许压缩、概括与重组，几何细节服务于画面阅读，不承担文保测量用途。

## 文案与观景契约

`src/data/garden.content.ts` 保留留园 `UI_CONTENT` 的所有既有字段，并增加 `gardenName`、`seal`、`romanName`。`VIEW_CONTENT` 的四个键固定为 `overview`、`lotus`、`hall`、`bridge`；各项均提供 `label`、`eyebrow`、`description`。观景文案描述当前艺术化场景，不将构图选择写成已核对的历史事实。

## 性能预算与资产自检

目标预算为三角面数量 **小于 150,000**、网格数量 **小于 160**。2026-10-04 在本临时资产目录执行严格 TypeScript 检查、esbuild Node bundle 检查及实际 `createGarden()` 遍历：**28 个语义对象、77 个 mesh、101,619 个三角面**；计数口径为每个 Mesh 的 index.count/3 或 position.count/3，含树冠、栏杆、屋面瓦缝、池岸与底座全部几何。实际包围盒为 `[-17.07,-0.93,-12.57]` 至 `[17.07,5.63,12.57]`，位于声明的 `SCENE_BOUNDS` 内。

自检还确认两个独立构建的几何/颜色字节哈希一致、所有顶点有限；调用 `dispose()` 两次时，77 个最终几何和 8 个共享材质均恰好释放一次。临时测试只链接了既有依赖，交付代码没有跨园运行时依赖。

以 Three.js 独立灯光预览执行 Chromium 151 本地渲染，实际导出了 `overview-asset-preview.png`、`lotus-asset-preview.png`、`hall-asset-preview.png`、`bridge-asset-preview.png` 四张画面，HTTP 200，页面脚本错误为空。预览中池面作为前景留白，北堂和双岛可辨，主曲桥连续延伸至东岸；这些截图只证明资产预览，不能代替最终界面的浏览器验收。

主代理仍需核实最终界面中的桥岸衔接与遮挡、移动端观景位、交互、无障碍和生产部署。上述项目尚未在本子任务中执行。

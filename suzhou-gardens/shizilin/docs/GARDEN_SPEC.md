# 狮子林艺术化微缩景观规格

主题为**石境回转**。本园以洞壑交错的低连绵假山为主体，池面偏向东侧，亭、上层小桥与折廊承担空间尺度和路径提示。模型是艺术提炼，既不是全园缩尺复原，也不声称具有可供施工或导航的尺寸精度。

## 空间与独立性

- 本园独立根场景名为 `shizilin-artistic-miniature`，固定初始化种子 `2026100417`。
- 底座设计尺寸约 28 × 23 单位；坐标、比例、高差、桥长、亭位置与廊线均为艺术化安排，实物尺寸与位置待核对。
- 三个独立区域为 `stone-labyrinth`、`eastern-water`、`turning-courts`。所有 19 个布局对象均保留对应 id 组。
- 西侧与中部是连续洞壑岩体；东侧是池亭留白；北、西、东折廊和南侧短廊围出有开合的院界。该重心区别于以孤立高石峰为核心的庭院构图。
- `huxin-pavilion` 与 `zhenqu-pavilion` 是用户提出的湖心亭、真趣亭式意向，模型仅为程序化点景亭。现阶段不把其柱数、屋面、材质、朝向或位置写成史实。
- 本园不运行时导入兄弟园的布局、几何、石峰、名称或资源；所用 Three.js API 为本园直接依赖。

## 岩体与路径

`stone-labyrinth` 使用初始化阶段一次采样的 66³ MarchingCubes 隐式场。有限的、定向的十一个长短岩褶经过平滑连接后形成整体；四个预先设计的洞穴凹口、两条不同尺度的贯通洞和有限的横向上层裂隙在体积场中实际相减。低石台、长脊和数个不同高度、宽度、倾向的峰肩共同形成轮廓，不通过随机叠放石球生成。

主洞沿世界 z 轴贯穿岩群，中心约为 `x=-6.7, y=1.25`。洞顶和内壁具有真实表面，材质保持 `THREE.FrontSide`，无需双面显示补救。高桥在两处岩肩之间跨过主洞，并在两端用有限踏步回接石径；水边桥与高桥具有不同材料、尺度和曲线。

石面用连贯的低频风化纹、有限细纹和顶向色洗表现手作哑光。建筑屋面有真实厚度或闭合边缘，采用青灰瓦、浅墙、素木，不使用反射水面、金色装饰或动画采样。

## 观景与界面

四个预设为 `overview`（石境回转）、`rockery`（洞壑寻径）、`waterside`（池亭相望）、`corridor`（廊转见石）。机位、focusId、区域、正交缩放跨度均存在本园的 `garden.views.ts` 中。缩放依宽高比选择较小值；交互沿用旋转、缩放、返回全园的约定。界面文案集中于 `garden.content.ts`，完整提供既有 UI keys 与本园 `gardenName`、`seal`、`romanName`。

## 可验收条件

1. 布局 id 唯一，机位 focusId 与 regionId 匹配，所有布局对象在场景内有自己的命名组；建筑有 `body` 与 `roof` 子组。
2. 场景实际三角面少于 170,000，网格少于 180；实际几何包围盒在 `SCENE_BOUNDS` 内。
3. 在岩群子树上进行 FrontSide Raycaster 检查：主洞中心射线零交点；向邻近实岩移动后应有交点；洞内向上检查应命中洞顶。
4. 相同种子与配置重复初始化产生相同几何；运行期间不继续采样或生成几何。
5. 四机位桌面与窄屏检查需能识别对应主体，画面没有 WebGL 初始化错误；交互、重置、错误状态等正式应用验收由集成后执行。
6. 一次 dispose 释放所有返回网格几何与八个共享材质；重复 dispose 不重复释放。初始化模板与临时 MarchingCubes 缓冲几何在构建结束时释放。

## 2026-10-23 用户批准的光影与水面扩展

用户同意先以狮子林制作晨光、水面与物体细节样板。本段替代旧规格中“不使用反射水面”“不使用动画采样”对本轮池面的限制，其余构图、洞口、机位、固定种子和 170,000 三角面预算继续适用。

池面采用与原池岸一致的 CatmullRom 轮廓、浅深色带和低幅程序化波纹法线。平面倒影使用沿水面镜像的正交相机，保留原投影与缩放，裁剪水下几何；相机未改变时复用倒影。粗指针设备使用 256²、其他设备使用 512² RenderTarget，波纹最多按 12/24Hz 调度。减少动态效果及实际离开视口时停止波纹；倒影绘制失败时恢复渲染器状态并退化到普通着色池面。

石山使用本园前一版原创 GLB 经 Blender 加浅褶皱、UV、顶点遮蔽及 1024² 切线法线烘焙，不新增洞道或改变真实名称。沿原批次添加柱脚、瓦垄、椽木与岸石接缝，不运行时反复生成几何。水面材质、纹理和目标由挂载实例持有并释放，加载缓存不随实例销毁。

本轮最终几何为 40 网格、109,106 三角面；浏览器另有接收阴影平面，主画面最多记录 109,108。真实证据见 [water-1 报告](reviews/water-1/REPORT.md)。

## 2026-10-23 时辰扩展

用户要求增加时辰效果。四个独立艺术光照预设为 dawn/卯时、noon/午时、dusk/酉时、night/亥时；手动选择，默认晨光，不依赖系统时间、网络或天文服务。允许定向光改变、暮夜灯笼发光及页面配色变化，原固定光照限制由本段替代，原四机位/洞口/预算继续适用。

按时辰 ID 同步光源、水色、倒影与缓存阴影失效；相机未动也必须重抓新倒影，完成后继续复用。切换不重新创建园景、GLB/法线或水面目标，不影响音乐。六处小灯笼含十八个网格、216 三角面；仅两座亭有点光，均不投射额外立方体阴影。园景与灯笼共 58 网格、109,322 三角面，加接收阴影平面为 59 网格、109,324 三角面，仍在原预算内。

真实四时辰与原四机位、移动布局、缓存和资源不增长证据见 [时辰报告](reviews/time-1/REPORT.md)。这不是季节/天气系统、实时日出日落或史实照明复原。

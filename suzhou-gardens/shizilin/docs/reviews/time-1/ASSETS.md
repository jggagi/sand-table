# 时辰资产与来源

本轮没有下载或生成新图片、音乐、模型或贴图。继续使用本园上轮已提交的原创石体 GLB/法线与音乐，字节不变；来源与 Blender 制作见 water-1/ASSETS.md。普通运行不需要 Blender，没有新增 npm 依赖或锁文件变动。

新增六个程序化小灯笼，位置由本园亭廊布局计算。十八个简单盒体 mesh 共216三角面，两座亭各一个不投影的暖色点光；其余廊灯使用发光材质。月光/太阳、天光和水色在 garden.time.ts 定义，是艺术化预设，不声称历史灯具样式或天文计算精度。

所有 time-1 JPG 均为实际 Chromium151/SwiftShader 对最终本地生产构建的截图，无生成图、补绘或后期修饰。园内四时辰截图保留页面实际配色。浏览器像素对照临时统一纸色，仅用于排除 CSS 背景导致的差异；交付截图没有此覆盖。入口预览由 capture-time-preview.mjs 对默认晨光实际全园画布直接截图产生，完整机位、哈希与字节见 preview-results.json。

# 沧浪亭 · 水外山林

这份规格定义独立的艺术化微缩景观。约 30 × 24 的底座尺寸、所有坐标、树种组合、建筑尺寸与墙廊转折均经过艺术压缩，不代表测绘结果、历史全园平面或实地游线。

## 空间主线

外河沿底座左侧向前缘弯行，水面与园内丘林始终被复廊分隔；本园不采用中央大池布局。正面与西侧两段复廊相接，中间为有真实圆形、菱形漏窗的暖白墙，两边都是开放柱廊和疏栏。两侧漏窗孔洞实际贯穿墙厚，可以同时借景园内与园外。

园内中心偏西是一座宽缓土石小丘。沧浪亭式开放亭坐在丘顶石台，山体没有独立竖直石峰。低缓叠石依坡散布，前侧阶梯联系廊与丘顶。较低、较宽的明道堂意向建筑置于东侧，留出前庭与稀疏过渡空间，其造型和尺寸不是实地复原。

植被分三层：后部阔叶树组成较密背景，坡上的姿态松树以弯干和不等高枝叶展开，小阔叶树与两丛竹形成中层。水外只有两株较小树，保留河面的疏朗留白。树木不使用单个球冠；松树枝叶较扁，阔叶枝叶更厚，按固定种子生成。

## 造型与资源

- 色彩：暖白墙、灰绿瓦、哑光丘石、土绿地面与浅矿绿河面。
- 建筑必须保留 `body-*` 与 `roof-*` 两个子组；各配置 ID 对应独立语义组。
- 固定种子 `2026100427`，根组名 `canglangting-artistic-miniature`。
- 每个语义组按材质合并网格，全景共享 9 个材质。生成不进入渲染循环。
- `createGarden()` 返回 `{ group, dispose }`；资源释放幂等，释放所有输出几何和共享材质，并移除组内对象。
- 模型预算严格小于 160,000 三角形与 180 mesh。

## 四个视角

| ID | 中文标题 | 构图目的 |
|---|---|---|
| `overview` | 水外山林 | 同时看到沿边外河、分隔复廊与丘亭密林 |
| `waterside` | 隔水看园 | 从前左侧看河面留白与复廊之后的高低层次 |
| `pavilion` | 丘上望亭 | 将开放亭、石台、姿态松与坡面放在主画面 |
| `corridor` | 复廊两望 | 以略斜视角看到疏栏、真实漏窗和墙后山林 |

机位是微缩模型的观景构图，没有模拟或宣称游客能够走到的真实位置。`getFittedZoom()` 根据视口宽高与预设所需空间跨度，兼容横屏与竖屏；接入应用后仍须实际浏览器检查四个预设和窄屏构图。
